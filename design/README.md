# UX Variant A/B Design Brief

Create only the critical checkout screen rather than an entire e-commerce product.

## Variant A — Baseline
Include:
- Checkout title
- Contact information
- Shipping address
- Payment area
- Order summary
- Subtotal / shipping / total
- Primary CTA with baseline hierarchy

Suggested CTA: `Continue`

## Variant B — Proposed
Keep the content and task as comparable as possible. Change only the intervention needed for the hypothesis:
- clearer primary CTA hierarchy;
- explicit next-step wording;
- clearer checkout progress;
- reduced competing visual emphasis.

Suggested CTA: `Continue to Payment`

## Controlled-experiment principle
Do not redesign the entire interface. If many elements change simultaneously, the experiment cannot isolate which design change produced the effect.
