# Research Documentation

This folder contains the methodological layer of the UX A/B Testing portfolio project.

## Files

- `experiment_design.md` — research objective, hypotheses, statistical design, decision framework, and UX transfer.
- `metric_framework.md` — primary, secondary, and guardrail metrics for a production UX experiment.
- `experiment_findings.md` — concise interpretation of the actual public A/B dataset results.

## Relationship to the Notebook

The notebook contains the full executable statistical analysis. The research files summarize the reasoning that sits around the code:

**question → design → metrics → evidence → decision → limitations**.

## Integrity Note

The Kaggle dataset analyzes `ad` vs `psa`. The UX checkout variants are conceptual and are not presented as the source of the public observations.
